# نظام محاسبي محلي - إصدار أولي احترافي (واجهة عربية)

ملخص:
- تطبيق سطح مكتب محاسبي (قيد مزدوج) يعمل محلياً باستخدام SQLite.
- واجهة عربية كاملة (RTL)، يمكن تشغيله على Windows 7/8/9/10/11.
- الضرائب تُدخل يدوياً داخل كل قيد/سطر أو حقل إجمالي الفاتورة.
- يمكن لاحقاً تغليف التطبيق كـ EXE (PyInstaller) وإنشاء مُثبت (InnoSetup).

متطلبات:
- Python 3.8+ مثبت
- PyQt5
- pip install pyqt5
- (للبناء:) PyInstaller و InnoSetup (أو NSIS) على جهاز البناء

تشغيل سريع (لتجربة بدون بناء EXE):
1. أنشئ هيكل المجلد:
   app/
     main.py
     db.py
     schema.sql
   build/
     build_windows.bat
     README_build.txt
   README_ar.md

2. ثبّت المتطلبات:
   pip install pyqt5

3. شغّل التطبيق:
   python app\main.py

إنشاء EXE (مبسط):
1. ثبت PyInstaller:
   pip install pyinstaller

2. نفّذ السكربت:
   build\build_windows.bat

هذا سينتج ملف exe داخل مجلد dist\؛ يمكنك بعدها استخدام InnoSetup/NSIS لإنشاء مُثبت.

ملاحظات مهمة:
- على Windows 7 قد تحتاج لتثبيت Visual C++ Redistributable (2015–2019).
- احفظ النسخة الاحتياطية من ملف قاعدة البيانات (data.db) بانتظام.
- هذا الإصدار MVP (وظائف أساسية متكاملة). يمكنني توسيعه لإضافة: طباعة/PDF، تقارير متقدمة، مخزون، رواتب، صلاحيات مستخدمين، استيراد/تصدير Excel، تشفير النسخ الاحتياطي، إلخ.

إذا تريد، أجهز إصدار EXE ومثبت وأرفع لك الروابط للتحميل بعد أن تُعطيني إذن الرفع أو عنوان بريد/خدمة تخزين تفضّلها.
